# DJ Claude Skratch

A scratching machine for Ableton Live (Max for Live instrument). One deck, one fader, one
phrase: a modelled record hand and fader hand perform sixteen scratches in time with Live.

**Status: designed, not built.** `docs/02-build-instructions.md` is the build spec.
`ref/` holds the reference engine the demos were made with (`python3 make_demos.py`).
