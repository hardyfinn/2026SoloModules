# Installing a VCV Rack plugin file on a Mac

## Summary
To install a .vcvplugin file, quit Rack, drop the file into the Rack plugins folder, then start Rack.
For Rack 2 on an Apple silicon Mac the folder is ~/Documents/Rack2/plugins-mac-arm64.

## Question
> where can i download the plugin?

## Answer
You can download it here: [ComperFable-2.2.0-mac-arm64.vcvplugin](https://github.com/hardyfinn/2026SoloModules/releases/download/preview/ComperFable-2.2.0-mac-arm64.vcvplugin). It's on the repository's "preview" release, it's the latest build, and it has all three modules: Comper, Walker and Rider.

To install it, quit Rack and drop the file into your Rack plugins folder (for Rack 2 on a Mac that's `~/Documents/Rack2/plugins-mac-arm64`), then start Rack. Older Comper Fable files are on the same release, so make sure you pick 2.2.0.
