# Dung Revisions (VCV Rack, Apple Silicon Mac)

A clock divider with two OR buses feeding a 16-step shift register that can
run in either direction, for learning the hardware away from the case.

- Install: drop `DungRevisions-2.0.0-mac-arm64.vcvplugin` into
  `~/Library/Application Support/Rack2/plugins-mac-arm64/` and restart Rack.
- Guide: `DungRevisions-Guide.html` (panel, display, five lessons, rig tips).
- Source and automatic builds: https://github.com/hardyfinn/dung-revisions
  (newest build always at Releases > latest).
