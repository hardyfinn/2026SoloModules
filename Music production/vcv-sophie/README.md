# Sophie (VCV Rack)

Sixteen-pad metallic FM percussion, ported from mestela/schwung-sophie (Ableton Move).
Source: https://github.com/hardyfinn/Sophvcv

- `Sophvcv-2.0.0-mac-arm64.vcvplugin`: copy to `~/Documents/Rack2/plugins-mac-arm64/` and restart Rack (or double-click it)
- `Sophie-Guide.html`: what every knob and jack does, patch ideas, audio demos
- `panel-preview.png`: the panel (the display text is a mock-up)

New builds appear at https://github.com/hardyfinn/Sophvcv/releases/tag/latest after each push.
