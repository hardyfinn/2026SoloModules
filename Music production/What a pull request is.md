# What a pull request is

## Summary
A pull request proposes merging a branch of changes into a repo's main code.
Merging is a button on GitHub and can be reverted later.

## Question
> Please explain pr to me again. I suspect I'm happy to merge all

## Answer
A pull request (PR) is a proposal to merge a branch of changes into a repo's main code. Until you merge it, the changes sit on their own branch and the main code doesn't have them. Merging is a button on the PR page on GitHub, and it's reversible, since you can revert it later.
