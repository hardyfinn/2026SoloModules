# Tuned Perc (VCV Rack, Apple Silicon Mac)

One percussion sample, tuned automatically. Tuned Perc detects the drum's
pitch, moves it to the nearest C, then plays it from V/OCT so it sits in key
with the track (0 V = the drum's own C).

- Install: drop `TunedPerc-2.0.0-mac-arm64.vcvplugin` into
  `~/Library/Application Support/Rack2/plugins-mac-arm64/` and restart Rack.
- Guide: `TunedPerc-Guide.html`.
- Source and automatic builds: https://github.com/hardyfinn/tunedperc
  (newest build always at Releases > latest).
