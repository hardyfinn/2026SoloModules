# House Keys: build instructions

Design by Fable, 2026-11-21, for Hardy. To be built by Opus. Read all of it before writing code.

Background and research: `/mnt/project-files/house-keys-vcv/01-research-and-proposal.md` and `02-revised-proposal-100-sounds.md`.

## 0. What this is, and the rules of the build

A polyphonic VCV Rack 2 voice module that plays 100 keyboard sounds of 1986 to 1992 Detroit and Chicago records (Derrick May, Kevin Saunderson, Mr. Fingers) by modelling the five machines those sounds came from. Hardy's standing request today is realism above everything else, and will review the 100 sounds and cut them down.

Rules:
1. **The DSP in this document is the design. Do not substitute your own.** Where something is ambiguous, pick the reading closest to the real machine, and write it in `docs/DECISIONS.md`. Where a number here is marked *est.*, keep it in one constants header per engine so it can be tuned later.
2. **The 100 sounds are in `data/sounds.py` and are part of the design.** Do not retune them by guesswork. Change a value only when a test in section 12 fails, and log each change.
3. No Korg, Ensoniq, Roland, Casio or Yamaha audio (ROM waves, samples) may be copied into the repo. Yamaha 4-operator voice parameter banks (`data/syx/`) are already in the repo and are used as data.
4. No brand or model names on the panel, in the module name or in sound names shown to the user. The manual may name the machines when explaining what each engine models.
5. Apple silicon Mac build only, through the repo's existing CI. `vcvrack.com` is blocked from the cloud container, so the Rack SDK cannot be downloaded here: test the engines offline with a host test program, check Rack-facing code against headers fetched from `github.com/VCVRack/Rack` (include/), and rely on CI for the real build.
6. Folder `HouseKeys/` in `hardyfinn/2026SoloModules`, on branch `claude/project-thread-rlng5f`. Follow `Heathrow/` for layout, Makefile, licence (GPL-3.0-or-later), brand "Haer", logo script, label sizes (controls 3.2 mm, jacks 2.9 mm). Plugin slug `HouseKeys`, module slug `HouseKeys`, name "House Keys", version 2.0.0, tags Synth voice, Polyphonic, Digital.
7. Get audio to Hardy early: as soon as the FM and POLY engines render offline, post short demo WAVs before finishing the rest.

## 1. Module

### 1.1 Jacks
Inputs: `V/OCT` (poly, up to 16), `GATE` (poly), `VEL` (poly, 0 to 10 V; unpatched means the fixed velocity of section 3.3), `SOUND` CV (0 to 10 V spans sounds 1 to 100, added to the knob), `TONE` CV, `DECAY` CV, `MOD` CV, `TWIN` CV (all ±5 V bipolar adding ±100% of range, except MOD and TWIN 0 to 10 V).
Outputs: `L`, `R`. If only L is patched it carries the mono sum.

### 1.2 Controls
| Control | Type | Function |
|---|---|---|
| SOUND | snap knob 1..100 | Selects the sound. |
| PREV / NEXT | buttons | Step the sound. They move the SOUND knob. |
| FM, POLY, PD, WAVE, SMPL | 5 buttons with lights | Jump to the first sound of that engine. Light shows the current engine. |
| display | text, 2 lines | Line 1: number and name, e.g. `001 Solid Bass`. Line 2: engine and, while a SAMPLER sound renders, `LOADING`. Use Rack's built-in ShareTechMono. |
| OCTAVE | snap knob −2..+2 | Added to the sound's own octave. |
| TONE | bipolar knob | Brightness. Centre is the sound as programmed. Mapping per engine in each engine section. |
| ATTACK | bipolar knob | Scales attack time, ×1/8 to ×8 (centre ×1). |
| DECAY | bipolar knob | Scales decay and release times, ×1/8 to ×8. |
| VELOCITY | knob 0..200% | Scales how much velocity does. 100% is the sound as programmed. |
| MOD | knob 0..1 | The mod wheel: vibrato or the sound's assigned wheel destination. |
| TWIN | knob 0..1 | 0 is off and costs nothing. Above 0 a second unit plays every note, detuned by up to ±12 cents (so 24 cents apart at full) and panned apart. |
| CHORUS | 4-position switch | SOUND (as programmed), OFF, I, II. |
| STAB | snap knob, 10 positions | OFF, 5TH, OCT, MIN, MAJ, MIN7, MAJ7, DOM7, SUS4, MIN9. Section 3.4. |
| GRIT | knob 0..1, default 0.5 | Converter and age. 0 is idealised and clean, 0.5 is the real machine, 1 is a worn one. Per engine. |
| TAPE | knob 0..1, default 0 | Cassette stage, section 9.2. |
| LEVEL | knob | Output level, default so one note at velocity 100 peaks near 5 V. |

Context menu: polyphony limit (4, 6, 8, 16; default 8, the machines were mostly 6 or 8 voice), "Load 4-operator voice bank (.syx)…" then a submenu of its 32 voices (the chosen voice plays through the FM engine until SOUND changes, display shows `USR name`), and "Fixed velocity when VEL is unpatched" (64, 100, 127; default 100, except FM sounds which use 64 est., because the DX100's own keys had no velocity).

Panel: about 26 HP, white or light silver with black text to sit with Hardy's other panels, generated by a script that also writes the layout header (as in Fallen's `make_panels.py`). Text labels everywhere. Group the panel left to right: SOUND block with display and engine buttons, PLAY block (OCTAVE, STAB, VELOCITY, MOD), SHAPE block (TONE, ATTACK, DECAY), MACHINE block (TWIN, CHORUS, GRIT, TAPE, LEVEL), jacks along the bottom.

## 2. Architecture

```
V/OCT, GATE, VEL -> note logic (stab, stealing) -> engine voices -> engine mix (mono or stereo)
   -> chorus (stereo) -> tape (stereo) -> level -> soft limit -> L, R
```
- One engine is active at a time. On SOUND change: release all notes over 20 ms, switch, never click.
- `Engine` interface: `setSound(index)`, `noteOn(voice, pitch, velocity)`, `noteOff(voice)`, `setMacros(...)`, `process(float* L, float* R, int n)`. Each engine owns its voices and its own oversampling.
- Engines run in blocks of 16 host samples. Latency under 1 ms except the FM resampler (section 4.5).
- No allocation on the audio thread. SAMPLER memory is rendered on a worker thread and swapped in with an atomic pointer.
- Loudness: `tools/gen_sounds.py` (or the host test program) renders every sound at velocity 100 (C2 for sounds with octave ≤ −1, else C4), measures the peak over the first 2 s, and stores a trim so that peak is −12 dBFS, where 0 dBFS is 10 V. Regenerate the trims whenever a sound or an engine changes.
- Output soft limit: `y = 12·tanh(x/12)` volts.
- Everything random is seeded and deterministic (`hash(voice index, sound index, counter)`).

## 3. Note logic

### 3.1 Pitch
`note = 60 + 12·V`. `f = 261.6256·2^V`. The sound's octave and OCTAVE add whole octaves.

### 3.2 Voices
Channel c of the cable is voice c. Rising GATE above 1 V is note on, falling below 0.5 V is note off. V/OCT is followed continuously while the gate is high (glide and pitch CV work). Mono sounds (`mono=True`) use last-note priority with legato glide.

### 3.3 Velocity
`v = clamp(VEL/10, 0, 1)·127`, or the fixed value when unpatched. Effective velocity for an engine: `v' = 64 + (v − 64)·VELOCITY` clamped to 1..127 (so at 0% everything plays at 64).

### 3.4 STAB
With STAB on, each played note sounds a chord: semitone offsets 5TH {0,7}, OCT {0,12}, MIN {0,3,7}, MAJ {0,4,7}, MIN7 {0,3,7,10}, MAJ7 {0,4,7,11}, DOM7 {0,4,7,10}, SUS4 {0,5,7}, MIN9 {0,3,7,10,14}. All chord notes share the gate and velocity. Chord notes take engine voices; total engine voices stay within the polyphony limit by stealing the oldest note's chord. Each chord note's level is scaled by `1/sqrt(notes)`. This is the sampled-chord effect: the chord moves in parallel.

## 4. FM engine (sounds 1 to 30)

Models the DX100 as it really was: a small CPU translating a voice into register writes for a YM2164 FM chip, whose output goes through a floating-point DAC. LatelyBass uses the TX81Z's YM2414.

### 4.1 Chip core
Vendor **ymfm** by Aaron Giles (BSD-3-Clause, compatible with GPL-3) into `HouseKeys/src/third_party/ymfm/`: `ymfm.h`, `ymfm_fm.h`, `ymfm_fm.ipp`, `ymfm_opm.h/.cpp`, `ymfm_opz.h/.cpp`, plus its LICENSE. Fetch from `github.com/aaronsgiles/ymfm`. Use class `ym2164` if present, otherwise `ym2151` (the differences do not affect these voices), and `ym2414` for OPZ sounds. Clock 3,579,545 Hz, so the chip's sample rate is clock/64 = 55,930 Hz. Read the register comments at the top of `ymfm_opm.h` and `ymfm_opz.h` before writing the firmware layer.

Each chip instance is one "unit" with 8 channels. Units: A1 (voices 1 to 8), A2 (voices 9 to 16, created only if the polyphony limit is 16), and B1, B2 when TWIN is above 0. Do not run units that have no sounding notes.

### 4.2 Voice data
Reuse and adapt `fallen/src/io/Syx4op.{hpp,cpp}` (Hardy's own code) to parse 32-voice VMEM dumps (4104 bytes, header `F0 43 0n 04 20 00`). `tools/gen_sounds.py` reads `data/syx/*.syx` and emits the 30 voices as byte arrays in `src/generated/Sounds.hpp`. VMEM per voice is 128 bytes; operators are stored in the order OP4, OP2, OP3, OP1, 10 bytes each: AR, D1R, D2R, RR, D1L, LS, [AME bit 6 | EBS bits 5-3 | KVS bits 2-0], OUT, CRS, [RS bits 4-3 | DET bits 2-0]. Byte 40: [SYNC bit 6 | FBL bits 5-3 | ALG bits 2-0]. 41 LFS, 42 LFD, 43 PMD, 44 AMD, 45 [PMS bits 6-4 | AMS bits 3-2 | LFW bits 1-0], 46 TRPS (24 is no transpose), 47 PBR, 48 flags, 49 porta, 50 FC vol, 51 MW pitch, 52 MW amp, 53 to 56 breath, 57 to 66 name, 67 to 69 PEG rates, 70 to 72 PEG levels, 73 to 83 TX81Z extension (per operator, same OP4 OP2 OP3 OP1 order, two bytes: [EGSFT bits 5-4 | FIX bit 3 | FIXRG bits 2-0], [OSW bits 6-4 | FINE bits 3-0]; then REV, FC pitch, FC amp).

Check: Solid Bass decodes to ALG 2 (stored 1), FBL 7, TRPS −12, OP4 OUT 70, OP1 OUT 99, all CRS 1.00 or 0.50. LatelyBass is the same voice with KVS and levels changed and one operator on waveform W5.

### 4.3 Firmware layer: voice to registers
Chip operator slots at register offset +0, +8, +16, +24 are M1, M2, C1, C2. The VMEM operator order OP4, OP2, OP3, OP1 is exactly that register order, so write the k-th stored operator to slot offset 8·k. ALG and FBL go straight to the CONNECT and FB fields, with both output bits (RL) set.

Per operator:
- **MUL and DT2 from CRS.** Build the 64 pairs (MUL 0..15, DT2 0..3), ratio = (MUL or 0.5 when MUL is 0) × {1, 1.414, 1.570, 1.731}, sort ascending by ratio. CRS is the index into that sorted list. Check: indices 0 to 8 give 0.50, 0.71, 0.78, 0.87, 1.00, 1.41, 1.57, 1.73, 2.00.
- **DT1 from DET** (0..6, 3 is centre): DET 3→0, 4→1, 5→2, 6→3, 2→5, 1→6, 0→7.
- **TL from OUT**: OUT ≥ 20 gives `99 − OUT`. Below 20 use {127,122,118,114,110,107,104,102,100,98,96,94,92,90,88,86,85,84,82,81}. Then add, per note, clamped to 127:
  - velocity: `round(KVS·(127 − v')/18)` *est.*
  - level scaling: `round((LS/99)·max(0, note − 24)·(8/12))` *est.*
- AR, D1R, D2R (5 bits), RR, D1L (4 bits) and RS (as KS) go straight in. AME sets the AMS-EN bit.
- OPZ only: waveform OSW, FINE, FIX and EGSFT go to the YM2414's extra registers as documented in `ymfm_opz.h`.

Per voice:
- **Pitch.** `k = note + TRPS − 24 − 13` in semitones, with the continuous fraction kept. Octave = floor(k/12), note code from {0,1,2,4,5,6,8,9,10,12,13,14} indexed by k mod 12 (code 0 is C#), KF = fraction × 64. Check: note 69 must sound 440.0 Hz within 2 cents. Write KC and KF every block so pitch CV is followed.
- **LFO** (the chip's own): LFRQ = round(LFS·255/99) *est.*, waveform from LFW (0 saw, 1 square, 2 triangle, 3 sample and hold), PMS and AMS direct. PMD = round(127/99·(PMD + MOD·MWpitch)) clamped, AMD likewise with MWamp. LFO delay is done by the CPU: ramp the depths from 0 over `(LFD/99)²·6 s` *est.* after note on. SYNC resets the LFO on note on. The LFO is shared by the 8 channels of a unit, as on the real machine.
- **Key on** all four operators. Key off on gate low.
- Pitch EG: apply only if any level differs from 50 (3-stage, rate 0..99 mapped `t = 8·2^(−rate/10) s` *est.*, level ±4 octaves at 0 and 99). None of the 30 voices should need it; check and note.
- Not used: breath, foot controller, portamento, EG bias.

### 4.4 Macros
- TONE: adds to the TL of every modulator operator (those that are not carriers in the algorithm): −24 steps at full right (brighter) to +32 at full left *est.*, each step 0.75 dB.
- ATTACK: offsets AR of carriers by ∓6 over the knob range. DECAY: offsets D1R, D2R and RR of all operators by ∓8 (D1R, D2R) and ∓4 (RR). Clamp to legal ranges; an AR, D1R or D2R of 0 stays 0.
- Update registers of sounding notes at most every 16 samples.

### 4.5 Converter and output
- Sum each unit to mono at 55,930 Hz. The real DAC (YM3014 on the DX100, YM3012 on the TX81Z) is floating point: 10-bit mantissa with a 3-bit exponent. ymfm provides this rounding (`roundtrip_fp` or equivalent in its output path). GRIT 0: bypass the rounding. GRIT 0.5: the real rounding. GRIT 1: mantissa cut to 8 bits and noise at −62 dBFS added. Interpolate the effect between those points by crossfading the outputs.
- Analog output filter: 2-pole Butterworth low-pass at 16 kHz *est.* plus a 1-pole high-pass at 12 Hz, both run at chip rate.
- Resample 55,930 Hz to the host rate with a windowed-sinc polyphase resampler (at least 32 taps, 80 dB stopband). This adds about 0.3 ms.
- TWIN: units B detuned by ± cents through KC/KF, and panned A to the left, B to the right by `0.6·TWIN`.
- Chorus (section 9.1) is off for FM sounds unless the CHORUS switch asks for it.

## 5. POLY engine (sounds 31 to 54)

Analog polysynths. `model` chooses the character: JUNO (one DCO, sub, chorus), JUP (two VCOs, drift, no chorus), JX (two DCOs, velocity, chorus), P800 (two DCOs, one filter shared by all voices, chorus). Run at 2× host rate, decimate with a half-band filter.

### 5.1 Fields and defaults
`oct` 0; oscillator 1 mix `saw` 0, `pulse` 0, `tri` 0, `sub` 0 (square one octave down), `noise` 0; `pw` 0.5; `pwm` 0 (LFO depth on pulse width, ±); oscillator 2 `lvl2` 0, `wave2` saw|pulse|tri|sq, `oct2` 0, `semi2` 0, `fine2` 0 cents, `sync` 0 (osc 2 hard-synced to osc 1), `sweep2` 0 (semitones of filter-envelope sweep on osc 2 pitch, for sync leads); `hpf` 0..3; `cut` Hz at C4; `res` 0..1; `env` octaves; `kbd` 0..1; `velcut` 0 octaves at full velocity; `poles` 4; `fenv` [A,D,S,R]; `aenv` [A,D,S,R] or "gate" (2 ms on, 6 ms off); `lfo` {rate Hz, delay s, pitch cents}; `vel` 0..1 velocity to loudness; `mono`, `glide` s; `chorus` 0, 1 or 2.

### 5.2 Oscillators
PolyBLEP saw, pulse and triangle (integrated BLEP square). Sub is a square at half frequency, phase-locked. Oscillator level sum feeds the filter at a level where a single full saw peaks at 0.5 of the filter's tanh knee.
- JUNO, JX, P800 (DCOs): no drift, exact tuning, oscillator phase free-running (not reset at note on).
- JUP (VCOs): each oscillator of each voice has a fixed offset (±2.5 cents, hashed) plus slow drift (band-limited noise below 0.3 Hz, ±1.5 cents). Scaled by GRIT: ×0 at 0, ×1 at 0.5, ×3 at 1.
- P800: its oscillators are sums of square waves, so its "saw" is the stepped staircase `sq(f) + sq(2f)/2 + sq(4f)/4 + sq(8f)/8`. Use that for `saw` when model is P800.

### 5.3 Filter
HPF: JUNO 4 positions: 0 is a +3 dB shelf below 150 Hz *est.* (the bass boost), 1 flat, 2 high-pass 240 Hz, 3 high-pass 720 Hz, one pole. Other models: 0 flat, then the same.
LPF: four cascaded one-pole OTA stages with a tanh at each stage input and global feedback, solved zero-delay (one Newton step is enough at 2× oversampling):
`fc = cut·2^(env·E_f + kbd·(note − 60)/12 + velcut·v'/127 + lfo terms + TONE·3)`, clamped 16 Hz to 20 kHz. Feedback `k = 4.1·res^1.2`, so the top of the range self-oscillates. No bass compensation, the low end thins as resonance rises, as on these machines. `poles` 2 takes the output after stage 2 (JUP only).
P800: one filter and one filter envelope for the whole instrument: sum all voices before the filter, the envelope retriggers on any new note, key tracking follows the lowest held note.
Per-voice spread: cutoff offset ±3% hashed, scaled by GRIT as above.

### 5.4 Envelopes and LFO
ADSR with exponential segments (attack towards 1.3 so it is slightly convex, decay and release time constants = time/4). JUNO has one envelope: when `aenv` is a list use it anyway (the design treats `fenv` as the filter contour and `aenv` as the loudness contour for all models). LFO triangle, per instrument not per voice, with delay fade-in. MOD adds up to 30 cents of LFO vibrato on top of the sound's own.
Velocity: loudness `1 − vel·(1 − v'/127)`.
TONE: ±3 octaves of cutoff. ATTACK, DECAY scale both envelopes.

### 5.5 Output
Mono into the chorus. Add a noise floor at −78 dBFS·(GRIT/0.5) after the VCA.

## 6. PD engine (sounds 55 to 66)

Phase distortion, after the Casio CZ. Two lines. Run at 4× host rate, decimate.

### 6.1 Waveforms
`φ` is the phase 0..1, `a` the distortion depth 0..1 (from the DCW envelope), `out = −cos(2π·φ')` unless stated.
- SAW: `d = 0.5 − 0.49·a`; `φ' = φ/(2d)` for φ < d, else `0.5 + (φ − d)/(2(1 − d))`.
- SQUARE: `h = frac(2φ)`, `φ' = (floor(2φ) + min(1, h/(1 − 0.98a)))/2`.
- PULSE: `φ' = min(1, φ/(1 − 0.98a))`.
- DSINE: `φ' = φ·(1 + a)`, the cycle restarts at the wrap.
- SAWPULSE: `φ < 0.5` uses SAW mapped into the first half of the cosine; the second half holds then completes: `φ' = 0.5 + 0.5·min(1, (φ − 0.5)/(0.5·(1 − 0.98a)))`.
- RES1, RES2, RES3: `out = w(φ)·sin(2π·φ·(1 + 15a))` with window `w` = `1 − φ` (RES1), `1 − |2φ − 1|` (RES2), `min(1, 2(1 − φ))` (RES3).
With `a` = 0 every waveform is a sine (or silence for RES). Two waveform names alternate cycle by cycle.

### 6.2 Structure
Per line: waveform(s), DCW envelope `[start, A, peak, D, sustain, R]` giving `a`, amp envelope `[A,D,S,R]` or "gate". `dcwkey` 0..1 lowers `a` as pitch rises: `a·(1 − dcwkey·clamp((note − 48)/48, 0, 1))`. `mode`: "1" one line; "1+1'" two copies of line 1, the second detuned by `det` = (octaves, semitones, cents); "1+2'" line 1 plus line 2 (`w2`, `dcw2`, `amp2`, level `lvl2`, default 1) detuned by `det`. `ring` 1 multiplies line 1 by line 2. `vib` {rate, delay, cents}, `trem` {rate, depth}. `vel` scales loudness and, by half as much, `a`. `mono`, `glide`.
TONE adds ±0.35 to `a` (clamped 0..1). ATTACK, DECAY scale both envelopes.

### 6.3 Converter
GRIT 0: as computed. GRIT 0.5: quantise each line to 8 bits before its amp envelope and apply the envelope in 6 dB coarse steps plus 4-bit fine *est.* (the CZ's stepped amplifier, which gives its faint zipper on decays). GRIT 1: 7 bits and a 20 kHz zero-order hold (use box-integration, section 7.4).

## 7. WAVE engine (sounds 67 to 88)

After the Ensoniq SQ-80: three 8-bit wavetable oscillators into a 4-pole analog low-pass, four envelopes, three LFOs. Run at 2× host rate.

### 7.1 Voice
Per oscillator: wave, octave, semitone, fine (0..31, each 3.125 cents), level 0..63, two pitch modulations and two amplitude modulations (one of each is used in the data: `pm`, `am`). `am=1`: oscillator 1's output is ring-modulated by oscillator 2 (osc 2 itself still sounds). `sync=1`: oscillator 2 restarts when oscillator 1 wraps.
Oscillator amplitude = `clamp(level + am_depth·source, 0, 63)/63`. Pitch modulation in cents: `depth/63·1200·source` (depth 63 with a source at full scale is one octave, so an LFO at depth 3 gives ±57 cents at full LFO level).
The three oscillators sum, then soft-clip `tanh(1.2·x)/1.2` with x scaled so three oscillators at level 63 reach about 2.0 (the mild overdrive these machines had).
Filter: the same 4-stage OTA model as section 5.3. `fc = 20 Hz·2^((cut + m1 + m2 + TONE·40)/12.7)` *est.*, where `m = depth·source` in the same 0..127 units, `kbd` adds `kbd/63·(note − 60)` semitones-worth in those units scaled ×12.7/12. Resonance `k = 3.6·res/31` (it does not quite self-oscillate).
Final amplifier: envelope 4, then pan (`pan` 0..15, 8 centre).

### 7.2 Envelopes and LFOs
Envelope `[L1, L2, L3, T1, T2, T3, T4, LV, T1V, TK]`: from 0 to L1 in T1, to L2 in T2, to L3 in T3 and hold, then on release to 0 in T4. Levels −63..63 (divide by 63). Times 0..63: `t = 0.002·2^(T/5) s` *est.* (0 is instant). Linear segments, as on the machine. LV: levels scaled by `1 − (LV/63)·(1 − v'/127)`. T1V: attack time lengthened at low velocity `×(1 + T1V/63·(1 − v'/127)·3)`. TK: all times scaled `×2^(−(TK/63)·(note − 60)/24)`.
Default envelopes: e1, e2, e3 all zero; e4 = `[63,63,63, 0,0,0,10, 0,0,0]`.
LFO `[freq, wave, L1, delay, L2, mod]`: `f = 0.05·2^(freq/7) Hz` *est.*; wave TRI, SAW, SQR, NOI; depth ramps from L1 to L2 (0..63) over a time set by delay (`t = 0.02·2^(delay/8) s` *est.*, 0 is instant); `mod` source adds to depth (WHEEL at full adds 63). Default LFO: off.
Sources, all normalised to ±1 or 0..1: LFO1-3, ENV1-4, VEL (linear), VEL2 (squared), KBD ((note − 60)/36), KBD2 (0 below C4, then rising), WHEEL (the MOD knob), PRESS (0), OFF.
MOD knob with no wheel routing in the sound: adds up to ±30 cents of 5.5 Hz vibrato to all oscillators. ATTACK scales T1 of all envelopes, DECAY scales T2, T3, T4.
`mono`, `glide` (0..63, `t = 0.005·2^(glide/6) s`).

### 7.3 Wave memory
Rebuilt by synthesis at start-up (deterministic), never copied from the machine. Single-cycle waves: 256 samples, signed 8-bit, peak-normalised to ±120, in 8 band-limited versions (one per octave of played pitch: keep harmonics whose frequency at the top of that octave stays below 12 kHz). `a_n` is the amplitude of harmonic n, sine phase unless stated.

| GRIT 1 | 1/n for n in {1,2,3,5,8,13,21,34}, else 0.1/n, n ≤ 40 |
| GRIT 2 | n^(−0.5), odd n ≤ 31, sign from hash(n) |
| GLINT 1 | {1:.5, 8:.6, 9:1, 10:.6, 16:.3, 17:.4} |
| GLINT 3 | {1:.4, 2:.3, 12:.5, 13:1, 14:.5, 26:.3} |

Multi-cycle loops, 8192 samples spanning 32 cycles of the nominal pitch (so a partial at ratio r is rounded to the nearest 1/32): ALIEN (VOICE 1 at the loop start morphing to VOICE 2 at the middle and back, with ±6 cents of wobble), BREATH (noise band-passed around harmonic 6, Q 1.5, plus 0.2 of the fundamental), STEAM (noise high-passed above harmonic 10 with 3 slow amplitude swells over the loop), METAL (ratios 1, 2.76, 5.40, 8.93, 13.34 at 1, .6, .4, .25, .15), CHIME (ratios 1, 2, 3.01, 4.17, 5.43, 6.8, 8.21 at 1, .7, .5, .45, .3, .2, .12). Band-limit versions per octave as above.

One-shot attacks, 4096 samples spanning 16 cycles, played once then silent; τ in cycles: CLICK (one cycle of saw plus white noise, τ 0.5), THUMP (sine at half the fundamental τ 3, plus low-passed noise τ 1), PLINK (sines at 1, 4.2, 9.1, τ 4, 2.5, 1.5), PLUCK (saw spectrum whose harmonic n decays with τ = 8/n), MALLET (sine at harmonic 4 τ 2 plus a CLICK), PICK 1 (noise band-passed around harmonic 8 τ 1, plus saw τ 3), SLAP (pulse train of width 5% τ 2 plus noise τ 0.7), CHIFF (noise band-passed around harmonic 3, rising for 2 cycles, τ 6).

### 7.4 Playback and converter
A 32-bit phase accumulator reads the table with no interpolation (nearest lower sample). The output is therefore a staircase in continuous time. To render a staircase without host aliasing, **box-integrate**: each output sample is the exact average of the staircase over that output sample's interval (it is piecewise constant, so this is a short sum of value × covered fraction). Use this routine for WAVE and SAMPLER.
GRIT 0: 16-bit tables with linear interpolation. GRIT 0.5: 8-bit, no interpolation (the machine). GRIT 1: 6-bit, and each oscillator's phase quantised to a 15 kHz clock.

## 8. SAMPLER engine (sounds 89 to 100)

After the Ensoniq Mirage: 8-bit samples, a small memory, no interpolation, a resonant 4-pole analog filter per voice. The sounds it plays are models of instruments, "recorded" into that memory when the sound is selected, so the machine's limits shape them as they shaped the originals.

### 8.1 Memory
Per sound at most 131,072 samples (assert `zones × len × sr ≤ 131072`). Each zone is a wavesample "recorded" at root note `zones[i]` and rate `sr`, 8-bit, normalised to ±120 before quantising. Zone i covers notes from the midpoint below its root to the midpoint above. `loop = (start, length, crossfade)` in seconds: build the loop with an equal-power crossfade of that length at the loop end so it does not click, but do not otherwise smooth it. A looped zone plays start to loop end, then repeats the loop. Unlooped zones stop at the end.
Rendering happens on a worker thread when the sound is chosen (target under 0.5 s). Cache the last four rendered sounds.

### 8.2 Generators
All are additive or source-filter models computed offline in double precision, mono.
- **strings** {players, bright, marcato, body}: `players` sawtooth-like voices (harmonics 1/n rolled off by a 2-pole low-pass at `2 kHz + 6 kHz·bright`), each with its own detune (±9 cents hashed), start phase, vibrato (5 to 6.2 Hz, ±7 to 14 cents, fading in over 0.25 s) and attack time (20 to 70 ms). Sum, then a body filter of fixed resonances (violin section: peaks at 280, 460, 1000, 2700, 3400 Hz; `body="cello"`: 95, 180, 250, 520, 1500 Hz; each ±6 dB, Q 4). `marcato` 0..1 adds a bow attack: band-passed noise (1.5 to 5 kHz) of 60 ms and a level bump of `+6 dB·marcato` decaying over 180 ms.
- **piano** {hardness, strings}: for root frequency f0, partials `f_n = n·f0·sqrt(1 + B·n²)`, `B = 0.0004·(f0/261.6)^1.3` *est.*; amplitude `|sin(nπ/8)|·n^(−(1.9 − hardness))·e^(−n/(8 + 30·hardness))`; each partial decays with two time constants: `τ_n = (2.5 s·(261.6/f0)^0.6)/(1 + 0.02·n^1.7)` for 70% of its amplitude and `4·τ_n` for the rest; `strings` copies detuned by ±1.2 cents. Add a hammer thump: low-passed noise (600 Hz) decaying in 25 ms at −14 dB. Partials up to `0.45·sr`.
- **choir** {vowel, singers}: `singers` voices of a glottal pulse (harmonics n^(−1.5)), detune ±12 cents, vibrato 5 Hz ±15 cents, through formants ("aah": 700, 1150, 2800, 3500 Hz, bandwidths 110, 120, 170, 200), plus breath noise at −26 dB through the same formants.
- **brass** {players, bright}: saw voices, detune ±6 cents, through a low-pass whose cutoff rises from 500 Hz to `1.5 kHz + 3.5 kHz·bright` in 50 ms and settles 30% lower; formant peak at 1.2 kHz, Q 2, +6 dB; a 30 ms pitch scoop of −25 cents at the start.
- **orchhit** {}: strings (16 players, marcato 1) at the root, the octave above and the octave below, brass at the root and fifth above, and a timpani hit (sine at the root an octave down with partials 1, 1.5, 2, 2.5 decaying in 0.4 s), mixed 1 : 0.8 : 0.6, with an overall decay of 0.9 s.
- **upright** {}: plucked string: harmonics `n^(−1.6)·|sin(nπ/6)|`, `τ_n = 1.8 s/(1 + 0.15n²)`, a finger thump (noise 300 Hz, 15 ms) and a body peak at 110 Hz and 220 Hz (+5 dB, Q 3).
- **vibes** {motor}: partials at 1, 4.0, 10.1 with amplitudes 1, 0.25, 0.08 and decay 3.5 s, 0.7 s, 0.15 s (scaled by `(261.6/f0)^0.5`), a mallet click, and tremolo of depth `motor` at 5 Hz.
- **chord** {notes, voice, cut, res}: the chord itself is in the sample: for each semitone offset in `notes`, two detuned saws (±8 cents) one octave below and at the root, through one shared 4-pole low-pass at `cut` with `res` (the section 5.3 filter) and a fast filter envelope (2 octaves, 180 ms). Amplitude decays 0.6 s.

### 8.3 Voice
Two oscillators per voice read the same wavesample: the second detuned by `det` cents at level `mix`. Playback rate = `sr·2^((note − root)/12)` samples per second, no interpolation, box-integrated (section 7.4). Then the 4-pole filter of section 5.3: `fc = cut·2^(env·E_f + kbd·(note − 60)/12 + velcut·(v'/127 − 0.5) + TONE·3)`, `k = 3.8·res`. Filter and amp envelopes `[attack s, peak, decay s, sustain, release s]`: rise to `peak`, fall to `sustain·peak`, hold, release; exponential decays, linear attack. Velocity: loudness `1 − vel·(1 − v'/127)`.
GRIT 0: 16-bit memory, linear interpolation. GRIT 0.5: 8-bit, no interpolation. GRIT 1: 6-bit and every zone's rate halved (render at `sr/2`).
ATTACK, DECAY scale both envelopes. Run at 2× host rate.

## 9. Effects

### 9.1 Chorus
A bucket-brigade stereo chorus after the Roland ones. Mono in; two delay lines modulated by the same triangle LFO in opposite phase; L = dry + line 1, R = dry + line 2, each ×0.7.
- Mode I: 0.513 Hz, delay swinging 1.66 to 5.35 ms. Mode II: 0.863 Hz, same range. *est.* from published measurements of the Juno-60.
- Before the lines: 1-pole high-pass 80 Hz and a 3-pole low-pass at 9 kHz; after: 3-pole low-pass at 9 kHz. Delay read with cubic interpolation. Soft clip `tanh` at ±1 on the line input. Hiss at −72 dBFS·(GRIT/0.5) added inside the lines.
- A sound's own `chorus` (0, 1, 2) applies when the switch is on SOUND. For stereo engines (FM with TWIN, WAVE pan) process L and R through separate instances.

### 9.2 Tape
One knob, 0 is a true bypass. Models mixing down to cassette (Mr. Fingers) or narrow multitrack.
- Wow 0.55 Hz and flutter 7.3 Hz plus a little noise-modulated flutter, as delay modulation: depth `TAPE·0.12%` and `TAPE·0.06%` of speed.
- Record pre-emphasis (+6 dB shelf above 3 kHz), `tanh` saturation with drive `1 + 3·TAPE`, matching de-emphasis. This gives level-dependent treble loss.
- Head bump: +2.5 dB·TAPE at 75 Hz, Q 1.2. High-frequency roll-off: 2-pole low-pass from 18 kHz at TAPE 0.01 down to 6.5 kHz at TAPE 1.
- Hiss: noise shaped +6 dB per octave above 1 kHz, at `−70 + 14·TAPE` dBFS, only while TAPE is above 0.
