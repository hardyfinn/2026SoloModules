# Kanji for takiki

## Summary
"Takiki" is probably *takigi*, 薪 (firewood), also written 焚き木.
As a name it could be 滝木 or 瀧木, but names vary.

## Question
> Can you show kanji for 'takiki'?

## Answer
You probably mean **薪** (たきぎ, *takigi*), which means firewood. The same word can also be written **焚き木** (たきぎ), meaning "wood for burning".

Japanese doesn't really have a common word read "takiki" with a plain *ki*. If it's a surname or given name, it could be written something like **滝木** or **瀧木** (taki = waterfall, ki = tree). Names can use lots of kanji combinations, though, so the only way to know for sure is to see how that person writes it.
